# Experiments

Experiments are numbered sequentially and use descriptive kebab-case names:

- `001-checkpoint-safety`
- `002-safety-boundary-stability`

The first experiment establishes an external benchmark baseline. The second is
the programme's first original, book-derived challenge instrument: it studies
whether safety judgements survive controlled meaning-preserving shifts.

A new directory represents a distinct research question or a substantial follow-up study. Small variations of the same study should be represented by configuration files or run identifiers inside the existing experiment.

Each experiment should contain:

- a preregistered question and hypotheses;
- exact inputs, model revisions, and controls;
- a reproducible procedure;
- raw-output provenance;
- analysis code and uncertainty estimates;
- limitations and a conclusion, including null results.
