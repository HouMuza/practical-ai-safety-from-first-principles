# Safety Boundary Stability

Shared Chapter 17 study for measuring whether model safety decisions remain
stable under controlled paraphrase, language, context and obfuscation shifts.

This directory owns the protocol, threat model, preregistration, scenario data,
authoring rules and human-review rubric. It contains no subject-model choices.
Those live in model-family bindings such as
[`../../Puro-2B/studies/safety-boundary-stability.binding.json`](../../Puro-2B/studies/safety-boundary-stability.binding.json).

The included briefs are development material, not publishable outcomes. Before
a pilot, complete independent review, freeze approved scenario IDs, pin every
subject and evaluator revision, and record the selected evidence stage.
